A newspaper front page summing up the world news of **Wednesday 18 November 2026** in one image: APEC opens in Shenzhen as Trump lands in Manila for Quad talks, Ukraine hits the Crimean Bridge again, Iran drones strike a US radar site in Bahrain, Nvidia posts record $115.8bn quarterly revenue, and 30 more stories from every continent — with a numbered world map showing where it happened. Drawn entirely in pure Python 3.13 standard library (hand-rolled PNG encoder, built-in 5x7 bitmap font); no network, fully deterministic.

## Run it

```sh
python3 main.py
```

Writes `out/entry.png` (1024x1024 PNG, under 1 MiB). Set `MAKEFUN_OUTPUT_DIR` to choose another output directory. Running it twice produces byte-identical output.
